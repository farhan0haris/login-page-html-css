# Login Page

A responsive login and registration interface built with HTML5 and CSS3, featuring a distinctive Victorian-inspired visual style, polished typography, atmospheric lighting, subtle animations, and responsive layouts for desktop and mobile.

## Features

- Responsive login page
- Registration page
- Email / username field
- Password field
- Remember me
- Forgot password link
- Login and registration navigation
- Victorian-inspired visual design
- Subtle CSS animations and interactions
- Mobile-friendly layout
- Accessible semantic HTML

## Tech Stack

- HTML5
- CSS3

## Project Structure

```text
login-page-html-css/
├── index.html
├── register.html
├── style.css
├── README.md
└── assets/
```

## Running Locally

Open `index.html` in a browser.

Or run a simple local server if preferred:

```bash
npx serve .
```
